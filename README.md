# L.U.N.A.

**Русский** | [English version → README.en.md](README.en.md)

Голосовой помощник для Windows с открытым кодом. Скажите «Луна» и попросите: открыть программу или сайт, найти файл, поискать в интернете или просто ответить на вопрос. Луна ответит текстом и голосом.

> Статус: ранняя версия. Что-то может работать неидеально; проверки вручную описаны в [docs/MANUAL_CHECKS.md](docs/MANUAL_CHECKS.md).

## Что умеет

- **Голос и слово «Луна».** Скажите «Луна, открой ютуб» или нажмите горячую клавишу (по умолчанию `Ctrl+Alt+Space`) и говорите. Слово «Луна» по умолчанию выключено, включается в меню значка в трее.
- **Режим диалога.** После ответа Луна ещё некоторое время слушает продолжение без слова «Луна». Закончить: «спасибо», «стоп» или «отбой». Включается параметром `follow_up_s` в `luna.toml` (секция `[wakeword]`, 0 = выключено).
- **Открыть и закрыть программы.** «Открой телеграм», «закрой блокнот». Закрывает аккуратно, как кнопка «×» в окне. Принудительно закрыть зависшую программу можно только после вашего согласия.
- **Открыть сайт и поиск на сайте.** «Открой гитхаб», «найди на ютубе котиков».
- **Ответы из интернета.** «Какой курс доллара?», «кто выиграл вчера?»: поиск ddgs, ключ не нужен.
- **Найти и открыть файл.** «Найди резюме», «открой второй». Программы и скрипты Луна только показывает в Проводнике, не запускает.
- **Модели и провайдеры.** В меню трея — «Модели / провайдеры…». Можно подключить любой OpenAI-совместимый сервис (свой адрес, модель, ключ) или локальную модель из LM Studio. Порядок провайдеров меняется кнопками «Вверх» / «Вниз».
- **Голоса.** Онлайн-голос Edge «Светлана»; если его нет, то локальный Piper «Ирина» (только в личной сборке); если и его нет, то голоса Windows (SAPI).

## Скачать и установить

1. Скачайте `LUNA-Setup-<версия>-x64.exe` на [странице релизов](https://github.com/Orifdzhon/L.U.N.A/releases).
2. Запустите. Установка только для вашего пользователя: права администратора и Python не нужны.
3. Установщик не подписан, поэтому Windows SmartScreen покажет «Windows защитил ваш компьютер». Нажмите **Подробнее**, затем **Выполнить в любом случае**. Желающие могут сверить SHA-256 с указанным в описании релиза.

Публичная сборка без локального голоса Ирины (в Piper входит espeak-ng под GPL-3.0). Голоса Edge и Windows работают. Лицензии сторонних компонентов лежат в `THIRD_PARTY_NOTICES.txt` в папке установки.

## Первый запуск

При первом старте откроется окно ключей, если нет ключа облачной модели.

- **Groq** (нужен для облачных настроек по умолчанию, бесплатный): [console.groq.com/keys](https://console.groq.com/keys).
- **Gemini** (по желанию, бесплатный): [aistudio.google.com/apikey](https://aistudio.google.com/apikey).
- Нажмите «Проверить», затем «Сохранить» и перезапустите Луну. Ключи хранятся в Диспетчере учётных данных Windows, не в файлах.
- Позже ключи и провайдеров можно менять в меню трея: «Модели / провайдеры…».
- **Без ключей** программы и сайты всё равно открываются; для ответов нужен провайдер.
- **Локальная модель (LM Studio):** запустите сервер (Developer → Running), узнайте точный id модели командой `curl.exe http://localhost:1234/v1/models` и добавьте его в «Модели / провайдеры…» или в `luna.toml`: `[llm.providers.local] model = "<id модели>"`. Подробности: [docs/SETUP.md](docs/SETUP.md#4-local-fallback-lm-studio-optional).

Речевые модели (распознавание, слово «Луна») скачиваются при первом использовании, нужен интернет и несколько сотен МБ на диске C: (папку можно сменить, см. [docs/SETUP.md](docs/SETUP.md#data-folders-and-model-downloads)).

## Как пользоваться

Значок Луны живёт в трее; окно открывается пунктом «Открыть окно» в его меню. Примеры:

- «Луна, открой телеграм» / «закрой хром»
- «Открой ютуб и найди lofi» / «найди на википедии чёрные дыры»
- «Какая погода в Москве?» / «Сколько сейчас времени?»
- «Найди договор pdf», затем «открой первый»
- «Спасибо» — закончить режим диалога

Горячая клавиша, слово «Луна», голосовые ответы и автозапуск настраиваются в меню трея и в `luna.toml` (`%APPDATA%\LUNA\luna.toml`; пример с пояснениями: [luna.example.toml](luna.example.toml)). Подробнее: [docs/SETUP.md](docs/SETUP.md).

## Приватность

- **Голос:** с микрофона звук обрабатывается только после слова «Луна» или нажатия клавиши. Слово «Луна» ищется локально. Сама команда уходит в облачное распознавание Groq; без него работает локальная модель faster-whisper.
- **Тексты запросов** уходят выбранному LLM-провайдеру (Groq, Gemini или вашему). На бесплатных тарифах провайдер может использовать запросы для обучения: не диктуйте ничего личного.
- **Поиск в интернете:** запрос уходит в поисковую систему (ddgs).
- **Голос Edge** отправляет текст ответа на серверы Microsoft; Ирина и SAPI работают локально.
- **Локальная модель** (LM Studio) ничего никуда не отправляет.
- **Ключи** лежат в Диспетчере учётных данных Windows, в логи не попадают.
- **Файлы:** поиск идёт по вашему диску локально, содержимое файлов никуда не отправляется.

## Удаление

«Параметры» → «Приложения» → L.U.N.A. → «Удалить». Если Луна запущена, установщик попросит её закрыть. Затем будет вопрос **«Удалить также настройки, журналы, загруженные модели и сохранённые ключи API?»**

> **Внимание:** ответ **«Да»** **сбрасывает все настройки** (режим диалога, горячую клавишу, слово «Луна» и остальное), **удаляет загруженные модели** (потом их придётся скачивать заново) и удаляет сохранённые ключи. Если планируете переустановку, выбирайте **«Нет»** (по умолчанию): удалится только программа.

## Сборка из исходников

Нужны Windows 10/11, `git` и [uv](https://docs.astral.sh/uv/) (он сам поставит Python 3.13).

```
winget install astral-sh.uv
git clone https://github.com/Orifdzhon/L.U.N.A.git
cd L.U.N.A
uv sync --all-extras --dev
copy .env.example .env          # ключи Groq / Gemini (необязательно; .env не коммитить)
uv run luna                     # трей и окно
uv run luna --text              # текстовый режим
```

Полезные флаги `uv run luna`: `--voice` / `--no-voice` (голосовые ответы), `--listen` (горячая клавиша), `--wake` (слово «Луна»), `--minimized` (без окна), `--config PATH`, `--forget-keys`. Список: `uv run luna --help`.

Проверки разработчика:

```
uv run ruff check .
uv run ruff format --check .
uv run pytest
```

Установщик (нужен [Inno Setup](https://jrsoftware.org/isinfo.php)):

```
uv run --frozen --no-dev --group build python scripts/build_installer.py --edition public
```

Результат: `dist\LUNA-Setup-<версия>-x64.exe`. Флаги: `--edition {public,personal}`, `--skip-setup`, `--tag`. Подробнее: [docs/SETUP.md](docs/SETUP.md#build-the-setup-yourself).

Остальная документация (на английском): [требования](docs/PRODUCT_SPEC.md), [архитектура](docs/ARCHITECTURE.md), [roadmap](docs/ROADMAP.md), [правила разработки](CLAUDE.md). Бенчмарки LLM и слова «Луна»: [README.en.md](README.en.md#development).
